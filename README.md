# 🤖 Discord Bot - Match & Stats

## 📌 Présentation

Ce projet est un **Bot Discord** développé en **TypeScript** avec [discord.js](https://discord.js.org/).  
Il accompagne l’API en offrant une interface directe aux utilisateurs depuis Discord.

Le Bot permet notamment de :

- ⚡ Exécuter des commandes pour interagir avec l’API
- 📊 Consulter ses propres statistiques ou celles de son équipe
- 📝 Générer des prévisualisations de matchs au format tableau (Hlorenzi-like)
- 🌍 Fournir une expérience centralisée directement dans Discord, sans passer par une application externe

## 🛠️ Stack technique

- **Langage :** TypeScript
- **Librairie principale :** discord.js
- **Linting & Qualité :** ESLint
- **Conteneurisation :** Docker (production-ready)
- **CI/CD :** GitHub Actions

## 🌍 Cas d’usage

- Les joueurs peuvent consulter leurs performances directement dans Discord
- Les administrateurs d’équipe peuvent publier rapidement les résultats des matchs
- Le Bot facilite la communication et le suivi des statistiques sans quitter Discord
